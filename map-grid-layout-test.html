操作说明

  1. 选择建筑与可用等级，在建筑定位模式点击全场景扩展网格。
  2. 建筑以底部中心吸附；调整缩放、纵向压缩和锚点，使其贴合空地。
  3. 点击保存当前建筑位，位置会记录到浏览器本地。
  4. 切换到村民移动模式后点击目标格，村民会沿网格逐格移动。
  5. 村民序列帧由整数帧索引切换，不使用背景连续滚动动画。
