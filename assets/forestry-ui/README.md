# Forestry UI 资源整理

本目录保存从 ForestryMC 官方 GitHub 仓库获取的原始 UI 纹理与少量相关图标，当前只做本地归档，未接入网页试验页或游戏逻辑。

## 下载范围

- `official-github/ForestryMC/mc-1.12/textures/gui/`：完整 GUI 纹理，包含蜂房、分析器、图鉴、机器面板、槽位、错误状态、生态环境、任务触发器等。
- `official-github/ForestryMC/mc-1.12/textures/items/`：精选蜂种、蝴蝶、蛹、框架、花粉、蜂蜜、树果、肥料、树木培育和生态相关图标。
- `official-github/ForestryMC/mc-1.12/textures/blocks/`：精选分析器、蜂房、树木培育、离心机、木工机、发酵机、图鉴和生态设备方块图标。

当前共归档 260 个文件：GUI 166 个、物品图标 85 个、方块图标 9 个。
